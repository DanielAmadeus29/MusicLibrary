# MusicLibrary
This project is a music library system that allows users to create their own personal accounts and upload their own music. Each user has a private collection, meaning songs uploaded by one account are only accessible to that specific user.

Users can create playlists to organize their songs, making it easier to manage and listen to music based on mood, genre, or personal preference. Songs can be added to one playlist for better organization and faster access.

The system also includes a search bar feature that helps users quickly find content. Users can search for music based on song title, playlist name, or artist name, making the library easy and efficient to use even with a large number of songs.
